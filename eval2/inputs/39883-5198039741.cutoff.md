## Description
## Summary

Fixes rendering of tab-indented nested bulleted/numbered lists by normalizing tab indentation to 2 spaces while preserving 4-space tab stops inside fenced code blocks.

Fixes: #38436

---

## 🔍 Problem & Architectural Fix

- **Problem**: Zulip uses 2-space indentation for nested bulleted and numbered lists (`UListProcessor`, `ListIndentProcessor`). When users copy/paste tab-indented lists from external editors (Notion, VS Code, Obsidian), the upstream `NormalizeWhitespace` preprocessor expanded tabs to 4 spaces, causing list items to be misparsed as flat items or code blocks.
- **Solution**: Replaces `NormalizeWhitespace` with `ZulipNormalizeWhitespace`. It detects fenced code blocks line-by-line:
  - **Outside Code Blocks**: Expands tabs to 2 spaces (`LIST_INDENT_TAB_WIDTH = 2`) for nested list parsing.
  - **Inside Code Blocks**: Expands tabs to 4 spaces (`CODE_BLOCK_TAB_WIDTH = 4`), preserving standard code block tab stops.

---

## 🧪 Fixture Tests Added

Added two test cases to `zerver/tests/fixtures/markdown_test_cases.json`:
1. `ulist_nested_ulist_tab_indent`: Verifies tab-indented nested bullet lists render identically to 2-space indented lists.
2. `codeblock_tab_indent`: Verifies tabs inside fenced code blocks expand to 4-space tab stops (backend), and are preserved as-is by the JS frontend (via `marked_expected_output`).

I have managed to implement an extra function which added a pre-processing step in `web/src/compose_paste.ts`. When a user pastes plain text, the paste handler checks if the text contains a tab-indented list. If it does, it intercepts the text and safely converts all leading tabs into 2-space indents before inserting it into the compose box.

```
export function normalize_tabs_to_spaces(text: string): string {
    return text
        .split("\n")
        .map((line) => {
            // Check if the line starts with tabs followed by a list marker and a space
            if (/^\t+([*+-]|\d+\.)\s/.test(line)) {
                // Replace leading tabs with '2' spaces per tab level
                return line.replace(/^(\t+)/, (match) => "  ".repeat(match.length));
            }
            return line;
        })
        .join("\n");
}
```
