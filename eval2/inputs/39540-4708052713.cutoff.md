## Description
### Description

Fixes a visual bug in the right sidebar where a double focus outline is shown when navigating the buddy list with the keyboard. I saw this happening when working on the "Invite to organisation" button and got the fix approved in CZO.

The issue was that the .buddy-list-user-link container was getting our custom focus outline, but inside it the <a> was getting the default focus ring (verticle line/inner box artefact). The solution was to add outline: none; and text-decoration: none; to the inner <a> element in its :focus, :focus-visible and :active states.

 Fixes: https://chat.zulip.org/#narrow/channel/101-design/topic/focus.20styles.20for.20.27View.20all.20users.27/with/2477693

 How changes were tested:

Manually tested by opening the right sidebar and using the Tab key to navigate through the buddy list items. Verified that only a single, clean blue focus outline appears for each user link, perfectly matching the design of the "Invite to organization" button.
