## Description
### Description
Fixed keyboard (`Tab`) focus styling of the "Invite to Organization"
link in the right sidebar to match the existing focus style used by
action-heading links at the bottom of the left sidebar (e.g.,
"Browse more channels").

Previously, the link had no consistent focus indicator, and the
browser's default outline would appear inconsistently. Now it uses
`outline: 2px solid var(--color-outline-focus)` with
`outline-offset: -2px` on the parent `.invite-user-shortcut`,
matching the left sidebar's `highlighted_row` focus pattern.
Also suppressed the inner `:focus-visible` outline on
`.invite-user-link` to avoid double focus rings.

Fixes: #39172

**How changes were tested:**

* Launched the Zulip dev environment on local machine (`localhost:9991`).
* Traversed UI with `Tab` key to verify the focus ring appears correctly
  on the "Invite to Organization" link in the right sidebar.
* Confirmed focus ring uses `outline: 2px solid var(--color-outline-focus)`
  with `outline-offset: -2px`, matching the left sidebar's focus style.
* Verified that mouse clicks do not trigger the focus ring
  (handled by `:focus-visible` suppression on `.invite-user-link`).
* Tested in both Light and Dark themes.
