## Description
This PR adds severity-based emoji indicators to the Zabbix webhook integration. Zabbix's built-in, systematic severities have been mapped to distinct standard emojis to provide immediate visual context for incoming alerts.
Since Zabbix supports customizable trigger severity levels, unrecognized severity names are handled gracefully without errors.

Fixes part of #31240.

**Reference:** 
- [Zabbix Manual: Trigger Severity](https://www.zabbix.com/documentation/current/en/manual/config/triggers/severity)
- [Zabbix Manual: Trigger Severity Macros (`{EVENT.SEVERITY}`)](https://www.zabbix.com/documentation/current/en/manual/appendix/macros/supported_by_location)


**Severity Mapping:**
- Not classified ->  :grey_question: `:grey_question:`
- Information -> :information_source:`:info:`
- Warning -> :warning: `:warning:`
- Average -> :orange_square: `:orange_square:`
- High -> :rotating_light: `:rotating_light:`
- Disaster -> :sos: `:sos:`

**How changes were tested:**

1. Manually tested by sending fixtures to a local dev server using:
   `./manage.py send_webhook_fixture_message --fixture zerver/webhooks/zabbix/fixtures/zabbix_alert.json --url "http://localhost:9991/api/v1/external/zabbix?api_key=<API_KEY>"`
2. Verified the visual appearance of all severity levels in the local UI.
3. Updated and successfully passed automated backend tests via:
   `./tools/test-backend zerver/webhooks/zabbix/`
