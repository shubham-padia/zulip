## Description
Previously, the recipient header bars in digest emails used a hardcoded background color (`#9ec9ff`) and heavy black borders (`#000`) that did not reflect individual stream subscription colors or the modern Zulip web app recipient bar styling.

This pull request updates digest emails to:
- Dynamically style recipient header bars using the user's stream subscription color blended against white at 0.22 opacity, matching the web app's light theme recipient bar appearance while providing reliable rendering across desktop and mobile email clients (avoiding translucent rgba/8-digit hex).
- Modernize recipient block and header borders to `#e0e0e0` with rounded corners (7px).
- Update recipient header link styling and text color (`#262626`) for consistent readability.
- Pass subscription colors keyed by `stream_id`, gracefully falling back to `Subscription.DEFAULT_STREAM_COLOR`.
- Add unit test coverage for color blending, custom stream color rendering, and muted stream handling.

Fixes: #36685

### #37289 (PR, open): emails: Improve header bars colors and borders in digest emails.
Opened by CerealNotFound (COLLABORATOR). Labels: design, area: emails, size: XL, has conflicts, maintainer review. Assignees: prakhar1144.
Description: In this PR, header bars colors are set according to subscribed streams and borders are improved, consistent with the Zulip web app.

Approach for setting header bars colors:
- `subscription_colors` object is created for the user with keys as the `sub.recipient_id` and the value as the color of that subscription.
- `subscription_colors` is accessed inside `digest_block_header` using `message.recipient_id`
- `recipient_bar_color` is finally converted into rgba values using `hex_to_rgba` function to mimic "color mixing" used in the web
