## Description
Fixes #12203.

**How changes were tested:**

Added a new server setting `ADMINS_CAN_CHANGE_USER_EMAILS` (off by default) as described in the issue. When enabled, combined with the existing per-admin `can_change_user_emails` permission, an org admin can now change a user's email from the Manage User panel — this backend permission already existed but had no UI hooked up to it before this PR.

Also added a notification email to both the old and new address when an admin makes this change, since previously it happened silently.

Note: my first draft implemented this as a realm-level setting, but the issue specifically asks for a server-level setting (so Zulip Cloud can disable it globally while self-hosted servers opt in) — corrected to use `settings.ADMINS_CAN_CHANGE_USER_EMAILS` instead of a `Realm` model field.

### #12203 (issue, open): Server setting to allow admins to change user email addresses
Opened by ghost (NONE). Labels: area: settings (admin/org), help wanted, area: production, in progress. Assignees: Baluduvamsi2006.
Description: While investigating how to delete a user, I came upon the workaround of changing the user's email address that Tim mentioned in #10533. Instead of deleting the user (which deletes all that user's outgoing messages, etc) change the user's email address. This frees up the email address (important in corporate environments) while keeping all the user's messages in the system.

At a very basic level, this would mean giving admin users (with their API key) the ability to change a user's email address with a `PATCH` to `api/v1/users/{userId}`. 

Currently, that action will fail as it violates the security model for Zulip Cloud. Making it a server setting allows for Zulip Cloud to keep their security intact, but allow on premises installs to do it.

I believe #734 allowed a user to change their own email address. This is the admin component of that. Some more context in [this chat topic](https://chat.zulip.org/#narrow/stream/31-production-help/topic/Rest.20API.20for.20email.20editing/near/736223)
