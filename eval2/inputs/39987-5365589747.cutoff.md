## Description
Adds Asyntai, an AI assistant that answers questions from an organization's own website, documents and help center articles. It connects as an outgoing webhook bot and answers direct messages and mentions.

Registered in PLUGIN_INTEGRATIONS under "productivity", and added to INTEGRATIONS_WITHOUT_SCREENSHOTS, matching the other outgoing integrations (atolio, email, onyx) which work the same way and are exempt from example screenshots for the same reason: they do not send messages into Zulip, they reply to them.

Fixes: n/a — new integration.

**How changes were tested:**

Tested end to end against a self-hosted Zulip 12.2 server running from the official docker-zulip compose file:

- Created an outgoing webhook bot with the Generic interface pointing at the Asyntai endpoint.
- Sent direct messages to the bot and mentions in a channel through the API, and confirmed the bot's replies were posted in the correct conversation each time.
- Confirmed messages in a channel without a mention do not trigger the bot, and that the bot does not respond to its own messages.
- Confirmed the documentation page renders and that every link in it resolves.

**Screenshots and screen captures:**

None: this is an outgoing integration, which is exempt from example screenshots for the same reason as atolio, email and onyx.
