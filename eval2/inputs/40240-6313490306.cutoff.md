## Description
When a user grants permission for desktop notifications (from either the top navbar banner or the Settings > Notifications page), send a confirmation test notification immediately. This lets the user verify right away that notifications and system permissions are working as expected.

Fixes: #14433

**How changes were tested:**
1. Reset notification permission to "Ask" in browser site settings.
2. Reloaded Zulip and clicked "Enable desktop notifications" in the top banner. Granted permission and verified the test notification popped up.
3. Reset permission again and tested the "Enable desktop notifications" button in **Settings > Notifications**. Verified the test notification popped up after granting permission.
