## Description
Localized date labels on the last-updated footer and when hovering over charts in the analytics page. Updated time displays in the analytics page to match the user's clock preference. 

Fixes part of: #16094 

Based on the feedback I received from @shubham-padia and @laurynmm on the Zulip dev community chat, this PR does not address the remaining issue of the Plotly charts' x-axis labels not being translated. This is due to an ongoing transition from Plotly to Chart.js.

## My current fix

On /stats, some date strings rendered by Zulip's code weren't being localized.  `format_date()` in stats.ts hardcoded _en-US_ formatting, and `update_last_full_update()` used _en-US_ plus a hardcoded English " on " between the time and date.

I initially tried reusing `get_localized_date_or_time_for_format` from timerender.ts, but that helper depends on the global user_settings object, which is initialized during the main web app's startup and isn't initialized in the /stats bundle. I switched to formatting with Intl using page_params.request_language.
