## Description
Enforces lowercase characters and disallows spaces in custom Code Playground language names by updating `PLAYGROUND_LANGUAGE_REGEX` in `zerver/models/realm_playgrounds.py`.

*Note: This PR has been updated based on the UX discussion in CZO to ensure users receive loud frontend validation and clear UI hints instead of silently mutating their input.*

### Key technical changes:
- **Backend Model & Validation (`zerver/models/realm_playgrounds.py`)**: Updated `PLAYGROUND_LANGUAGE_REGEX = r"[a-z0-9_+-./#]+"` to disallow spaces and enforce lowercase language tags. Centralized `FENCED_CODE_LANGUAGE_REGEX = r"[a-zA-Z0-9_+-./#]+"` for Markdown code block parsing. Expanded `RESTRICTED_KEYWORDS` to disallow `'quoted'`.
- **Markdown Preprocessor (`zerver/lib/markdown/fenced_code.py`)**: Imported `FENCED_CODE_LANGUAGE_REGEX` so Markdown code block fences in chat messages parse uppercase tags (` ```PYTHON `) before lowercasing during HTML rendering.
- **Frontend Typeahead (`web/src/settings_playgrounds.ts`)**: Added typeahead `updater` function to populate the form input with canonical lowercase tags (`python`, `rust`, `javascript`) when selecting options from the settings dropdown.
- **Frontend Case-Insensitive Matching (`web/src/realm_playground.ts`)**: Made `get_playground_info_for_languages` case-insensitive and Pygments alias-aware so `data-code-language="Python"` matches `pythonpg` in chat messages seamlessly, ensuring backward compatibility for pre-existing playgrounds.
- **UI Templates (`web/templates/settings/playground_settings_admin.hbs`)**: Updated form placeholders and example hints from `Rust` to `rust`. Added a clear UI hint (`Must be lowercase letters and numbers.`) below the input box to explicitly warn users of the validation rule.

Fixes #24044.
Fixes #39847.
