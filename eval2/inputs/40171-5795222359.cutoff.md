## Description
Direct message is a synthetic dropdown option, not a real channel, so checking `can_use_empty_topic()` against its ID incorrectly disabled the submit button.

Renamed the misleading `channel_allows_empty_topic` flag to `topic_is_required`, and only consult `can_use_empty_topic()` for real channel IDs. This PR addresses the direct message option only;
the `#development help` mapping option has the same underlying issue and is left for a follow-up.

**How changes were tested:**

Manually verified in the "Generate URL for an integration" modal:
- Before selecting any Integration, the Copy URL button stays disabled.
- when a Integration is selected, the button becomes enables for the first attribute "Direct message to me".
