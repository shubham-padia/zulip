## Description
Fixes #40051.

**Describe your pull request here:**
This PR fixes a UI overflow issue in the settings modal on mobile viewports. Previously, the 'Edit email' section did not wrap or constrain its children properly, causing the email input and button to overflow the screen edge on small devices. By applying flex constraints, the elements now properly adapt to mobile widths.

**How changes were tested:**
Tested locally by running the development server, navigating to Settings -> Account & Privacy -> Email address, and resizing the browser to mobile width (under 500px). Verified that the overflow is resolved.
