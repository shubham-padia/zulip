## Description
Extends the existing lightbox to display code blocks in a larger view. Rendered
code blocks now have an Expand button that opens the code in the lightbox while
preserving syntax highlighting.

The expanded view provides actions to copy the code, open it in a configured
playground, and toggle line wrapping.

A later comment on the issue also suggests adding line numbers. This PR leaves
that for a follow-up because it is unclear whether line numbers should always be
shown or controlled by another toggle.

Implemented in collaboration with @johnnelsan 

Fixes: #5595

### #5595 (issue, open): Allow message code blocks to be zoomed in a lightbox.
Opened by showell (MEMBER). Labels: help wanted, area: message rendering, area: lightbox, in progress. Assignees: sinhSlumbering.
Description: We do a great job of displaying code blocks in messages with color syntax and scroll bars, but if your browser window isn't wide enough, and the code you're excerpting is wide, it's a pain to view the code.

One possible option would be to allow you the user to toggle wrapping on the code block, but I think this would be still kind of ugly for the user, and we mostly try to avoid changing the height of messages when we can, since it can cause strange redraw-related performance problems and expose edge-case-y quirks related to scroll position and expand/condense.

My proposal is to let users pop open a lightbox to see the code.   Or possibly even just another browser window that just has the text with almost no dressing.
