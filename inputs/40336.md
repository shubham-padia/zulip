## Description
This PR fixes invalid topic name for pull request events in the Gogs, Gitea.

@Alexis211 caught this in #40096: the gogs webhook built the topic for `pull_request` events from `pull_request.id`, which is the Gogs instance's internal database row ID, instead of `pull_request.number`, the user-visible PR number used in the message body links and in the UI integrations. 

Because `zerver/webhooks/gitea/view.py` reuses `gogs_webhook_main`, this affected Gog and Gitea together.

 On top of switching the topic to `pull_request.number`, it corrects the gitea `pull_request__merged` fixture, whose `number` had been set to the same value as `id` and masked the bug in that test case.
