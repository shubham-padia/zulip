## Description
The "Back" label at the top of the left sidebar's zoomed-in view (a channel's topic list, or the direct messages list) was hardcoded in English in `left_sidebar.hbs`. That kept it out of the translation pipeline, so it stayed in English for every display language. This wraps it in `{{t }}`, matching the rest of the template.

## Linked issues and PRs
### #40527 (issue, open): left_sidebar: "Back" button label is not translated
Opened by Toddthegod1 (CONTRIBUTOR). Labels: area: internationalization, area: left sidebar (display), area: left sidebar, in progress. Assignees: Toddthegod1.
Description: **Expected behavior:** When a user's language is set to something other than English, every piece of UI text should be translated, including the "Back" button shown when zooming into a channel's topic list (or the direct messages list) from the left sidebar.

**Actual behavior:** This "Back" label is hardcoded in English and is never translated, regardless of the user's language setting.

**Steps to reproduce:**
1. Go to Settings → Preferences and change the display language to any non-English language (e.g. Deutsch).
2. Click on a channel name in the left sidebar to zoom into its topic list (or open the direct messages list).
3. Look at the "Back" label at the top of the zoomed-in view.
4. It still reads "Back" in English, instead of being translated.

**Root cause:** In `web/templates/left_sidebar.hbs`, the string is written as plain `<span>Back</span>` instead of being wrapped in Zulip's `{{t '...' }}` translation helper, so it's never picked up by the translation-extraction pipeline.

I confirmed this isn't just a visual read of the template — running Zulip's own `./manage.py makemessages --locale en` (which is what `tools/check-frontend-i18n` uses) and checking the resulting `locale/en/translations.json` shows no `"Back"` entry at all, confirming this string is currently invisible to the whole translation system.

I have a one-line fix ready (wrapping it in `{{t 'Back' }}`, matching the convention used elsewhere in this same file) and will open a PR shortly.
