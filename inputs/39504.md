## Description
Adds [LiveKit](https://livekit.com/) as a new self-hostable video call provider.

This PR adds LiveKit as a provider following the same `/calls/<provider>/create` → signed-token URL → `/calls/<provider>/join`.  No LiveKit API call is made at creation time: rooms auto-create when the first participant joins. 

Every other provider is a complete conferencing app. LiveKit is **not** a conferencing app; it's just an SFU (selective forwarding unit) that routes media. There is no built-in call UI. This PR uses `livekit-client` JS SDK and ships a dedicated call page in `web/`.

Fixes:  #39343.
