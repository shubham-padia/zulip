## Description
The emoji picker arrow should match the section beside it. Matching the old translucent footer color alone still leaves a darker strip where the arrow overlaps the footer, so this uses an opaque equivalent of the same shade. Side arrows can touch either the emoji list or a shaded section in short windows, and now follow that section's color.

Addresses the emoji picker portion of #38931. The calendar arrow is left for a separate PR, as discussed in the issue.

**How changes were tested:**

- `./tools/test-js-with-node emoji_picker` (including regression coverage for side-arrow color changes).
- `./tools/lint web/src/emoji_picker.ts web/tests/emoji_picker.test.cjs web/styles/app_variables.css web/styles/popovers.css`
- Manually checked upward, downward, and sideways emoji picker placements in light and dark themes, including short-window placements beside the list and footer.
