## Description
Previously, `attachment_created` events were ignored. Now, Zulip notifies the stream when a user uploads an attachment to an issue.

Part of #16189.

**Summary of changes:**
* Removed `attachment_created` from `IGNORED_EVENTS` in `zerver/webhooks/jira/view.py`.
* Added `get_attachment_author` and `handle_attachment_created_event` to format notification messages containing the author, uploaded attachment link, and target issue.
* Added `attachment_created` routing to `JIRA_CONTENT_FUNCTION_MAPPER`.
* Added a webhook test fixture in `zerver/webhooks/jira/fixtures/attachment_created.json`.
* Added `test_attachment_created` to `zerver/webhooks/jira/tests.py` and removed `attachment_created` from `test_ignored_events`.

**Fixture generation details:**
* The payload fixture `attachment_created.json` was constructed following Atlassian's Jira Cloud Webhook API specification for the `attachment_created` event and formatted following Zulip's fixture guidelines, utilizing existing Jira test fixture schemas (`issue` and `user` objects) for consistency across test suites.

**How changes were tested:**
* Ran unit tests via `./tools/test-backend zerver/webhooks/jira/tests.py`. All 17 tests passed cleanly.
* Ran `./tools/lint zerver/webhooks/jira/` to ensure full compliance with formatting and typing standards.
