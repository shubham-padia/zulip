## Description
Fixes: Unused `filter_muted` template parameter, discussed in [#frontend > unused filter_muted in recent view](https://chat.zulip.org/#narrow/channel/6-frontend/topic/unused.20filter_muted.20in.20recent.20view) (split out of the [muting help docs discussion](https://chat.zulip.org/#narrow/channel/19-documentation/topic/muting.20help.20pages.20outdated)).

`get_recent_view_filters_params()` still passes `filter_muted` to `recent_view_filters.hbs`, but the template stopped using it when the "Include muted" filter button was replaced by the topic filter dropdown. This removes the parameter and the matching `filter_muted: false` entries in the test expectations.
