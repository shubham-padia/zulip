## Description
Previously, the Mattermost importer appended every thread reply directly after its root message in the single "imported from mattermost" topic, so the thread structure was lost after import.

This converts each Mattermost thread into its own Zulip topic, mirroring how the Slack importer handles threads (#27626): the thread root message stays in the main import topic with a link to the new thread topic, and the replies are moved into a topic named after the root message.

Fixes #38839.
