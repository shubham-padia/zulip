## Description
Fixes: Cramped lock-icon spacing in the settings sidebar, discussed in https://chat.zulip.org/#narrow/channel/137-feedback/topic/Settings.20sidebar.3A.20lock.20icons.20too.20close.20to.20scrollbar.

The lock icons sit close to the right edge of the settings sidebar. Give
that column the same width as the icon column on the left, using `em` so
both scale with the font size.

This continues Tanaya Pawar's work in #38338. It uses the equal-column
approach Tanaya suggested in the discussion rather than the original
padding change. Tanaya is credited as a co-author.

The wider column leaves slightly less room for labels. German labels were checked for wrapping, along with Arabic labels. The Arabic check used Zulip's existing LTR sidebar layout.

**How changes were tested:**

- [x] `./tools/lint web/styles/settings.css` and `git diff --check`.
- [x] Widths of 480, 768, 1280 and 1920px, and font sizes of 16px and 18px.
- [x] Personal and organization settings, collapsed and expanded menus,
      scrolling, and arrow-key navigation.
- [x] German and Arabic labels.

I also tested the local result myself and confirmed that the spacing, scrolling and arrow-key navigation looked good. No automated test was added for this CSS-only change.
