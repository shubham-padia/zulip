## Description
Zulip inserts the newline for modified Enter itself. Inside code blocks, db9ac4b674c made `handle_bulleting_or_numbering`
return early to skip list continuation, which also skipped inserting the newline. So Zulip wasn't inserting the newline on any OS. On Windows and Linux, the browser inserts one for Ctrl+Enter anyway, which is why this went unnoticed, but on macOS, Cmd+Enter inserts nothing.
Inside a code block, now we insert a plain newline itself (still without list continuation), so it works the same on every platform.

Fixes #40183.
[#issues > 📂 cmd+return after code block on Mac #40183](https://chat.zulip.org/#narrow/channel/9-issues/topic/.F0.9F.93.82.20cmd.2Breturn.20after.20code.20block.20on.20Mac.20.2340183/with/2528286)


**How changes were tested:**
-  Added a node test for Cmd+Enter inside a code block; confirmed it fails without the fix.
- Since I am on Windows, simulated Cmd+Enter with a synthetic keydown (metaKey: true) from the browser console: no newline inside a code block without the fix, newline inserted with it.

Manual test with a real Cmd+Enter on macOS is pending.

### #40183 (issue, open): macOS desktop: Cmd+Enter does not insert a new line after using a code block
Opened by lee-to (NONE). Labels: bug, area: compose (formatting), area: compose. Assignees: none.
Description: ## Description

In the Zulip web or desktop app on macOS, I cannot insert a new line with **Cmd+Enter** after using triple backticks (`` ``` ``) to create a code snippet in the message composer.

## Steps to reproduce

1. Open the Zulip desktop app on macOS.
2. Enable setting for '`Return` sends when composing a message'
3. Start composing a message.
4. Use triple backticks (`` ``` ``) to create a code snippet.
5. Press **Cmd+Enter** to try to continue on a new line.

Note: this bug does *not* replicate for quote blocks, spoiler blocks, or math blocks despite using the same ``` syntax.

## Expected behavior

I expect Cmd+Enter to insert a line break so I can continue composing the message.

## Actual behavior

Cmd+Enter does not insert a line break after using the triple-backtick code snippet. (Nothing happens)
