## Description
This PR completes #37683 by @CerealNotFound.

Read receipts opened as a modal, which is much heavier than the little information it shows, and disconnected it from the message actions menu it is launched from. It now opens as a popover anchored to that menu's button, with a header whose back button returns to the menu one level deeper in the same menu, per the design discussion on [CZO](https://chat.zulip.org/#narrow/channel/101-design/topic/Redesign.20read.20receipt.20modal.20to.20popover.2E/near/2493115).

Along the way, this fixes three bugs:

- The loading indicator never appeared on a slow network (reported by @-amanagr).
- An error banner stayed up even after a later poll succeeded.
- Opening a reader's user card with the keyboard stacked the cards on top of each other.

**`read_receipts` had no test coverage; this adds a test file for it.**

Fixes: #35004
CZO: [#design > Redesign read receipt modal to popover.](https://chat.zulip.org/#narrow/channel/101-design/topic/Redesign.20read.20receipt.20modal.20to.20popover.2E/with/2494288)
