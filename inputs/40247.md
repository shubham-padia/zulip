## Description
Fixes the stuck tooltips reported in [#issues > multiple tooltips staying open](https://chat.zulip.org/#narrow/channel/9-issues/topic/multiple.20tooltips.20staying.20open/with/2529805).

Tooltips in the DM list and on status emoji could stay open after the mouse moved away, if the element they belonged to was re-rendered while hovered (for example, typing in the zoomed-in DM list filter, or a user's status changing). This is reproducible on `main`; it became more noticeable on CZO with the larger emoji tooltips from #37972.

- DM list tooltips: the existing observer that hides them didn't cover the zoomed-in DM list, and missed a single row being re-rendered. This fixes both.
- Status emoji tooltips (buddy list, DM list, message headers): these had no handling for their emoji being re-rendered. This adds a small tippy plugin that hides the tooltip once its element is removed. It watches `document.body` because status emoji appear in several places, and only runs while a status emoji tooltip is visible.

### #37972 (PR, open): tooltips: Add Tippy tooltips for emoji with enlarged preview
Opened by Aadyot1 (COLLABORATOR). Labels: size: XL, accessibility, area: emoji, area: message feed (display), area: popovers and tooltips, design, chat.zulip.org review. Assignees: amanagr.
Description: Fixes #35170.

Emoji tooltips currently rely on the browser’s native title attribute, which only shows plain text and makes fine details hard to see.

This change replaces native tooltips with Tippy tooltips that display an enlarged emoji along with its :name:. The tooltip scales with the user’s font size and removes the native `title` attribute to avoid double tooltips.
Reactions are intentionally unchanged.
