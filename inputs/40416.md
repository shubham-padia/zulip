## Description
Fixes: Stale menu references in `docs/testing/manual-testing.md`, reported in [#documentation > manual testing page outdated](https://chat.zulip.org/#narrow/channel/19-documentation/topic/manual.20testing.20page.20outdated).

Several steps in the manual testing guide point at menus that have changed:

- Keyboard shortcuts are now in the help menu, and logging out is in the personal menu.
- The gear menu's settings entry is now called "Personal settings".
- There is no gear menu above the buddy list or in the left sidebar anymore, and channel settings no longer has a chevron next to each channel. The left sidebar entry point is now the "+" button's "Browse channels"; the other two steps are removed.
- The message menu is opened with the "Message actions" ellipsis button, not a chevron.

References that are still accurate (channel settings and inviting users from the gear menu) are unchanged.

**How changes were tested:**

- [x] Logged in as Iago on the dev server and opened the gear, help, personal, left sidebar "+" and user list menus to confirm where each option is now, and checked the channel settings list for a chevron.
- [x] `./tools/lint docs/testing/manual-testing.md`

One thing I left alone: the "Right-pane-pane menus" heading also looks like an old name, but I kept this PR to the menu references.
