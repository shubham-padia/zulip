## Description
Zabbix 7.x introduced significant layout changes, moving User, Media, and Action configurations out of the Administration tab and into top-level sidebar menus (Users and Alerts).

This updates steps 10 through 14 to reflect the modern Zabbix 7.x navigation flow, modal tabs, and button labels, ensuring the webhook guide remains accurate for current deployments.

**References:**
[Zabbix-manual: Configuration/Users and user groups](https://www.zabbix.com/documentation/current/en/manual/config/users_and_usergroups)

**How changes were tested:**

I manually verified this updated workflow on a fresh installation of Zabbix 7.4. 
* Generated the webhook endpoint in Zulip.
* Walked through the revised documentation steps to navigate the Zabbix 7.4 UI, successfully creating the Media Type, User profile, and Trigger Action.
* Tested the integration end-to-end by firing an alert to confirm the payload successfully arrives in Zulip.
