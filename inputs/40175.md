## Description
Building pyicu requires g++, but only gcc was listed. On Fedora/RHEL these are separate packages, so provisioning fails during uv sync.

Fixes: #40172

Added `gcc-c++` to `COMMON_YUM_VENV_DEPENDENCIES` in `scripts/lib/setup_venv.py`. This package provides the C++ compiler (`g++`) needed to build `pyicu`. On Debian/Ubuntu this isn't needed because `gcc` and `g++` come together, but on Fedora/RHEL they are separate packages.

**How changes were tested:**

- Removed `gcc-c++` from system (`sudo dnf remove gcc-c++`), ran `./tools/provision` — confirmed it installs `gcc-c++` automatically and provisioning completes successfully.
- `./tools/lint scripts/lib/setup_venv.py` passes with no errors.

### #40172 (issue, closed): Missing gcc-c++ dependencies for Fedora/RHEL in ./tools/provision
Opened by Ali-Razahaider (CONTRIBUTOR). Labels: bug. Assignees: none.
Description: ### Description

./tools/provision fails on Fedora/RHEL during the `uv sync` step because `pyicu` needs the C++ compiler (`g++`) to build, but only the C compiler (`gcc`) is listed in the dependencies. On Debian/Ubuntu this isn't a problem because both come together, but on Fedora/RHEL `gcc` and `gcc-c++` are separate packages.

Error Encountered: 

```
error: [Errno 2] No such file or directory: 'g++'
```

This happens in the [Advanced setup (non-Vagrant)]

(https://zulip.readthedocs.io/en/latest/development/setup-advanced.html) on Fedora or RHEL.
**Expected behavior:**
Running `./tools/provision` should install all required system packages and complete successfully.

**Actual behavior:**
The `uv sync` step fails while building the `pyicu` Python package because `g++` (the C++ compiler) is not installed. The error looks like:

```
error: [Errno 2] No such file or directory: 'g++'
```

The dependency list in `scripts/lib/setup_venv.py` includes `gcc` (C compiler) for Fedora/RHEL systems, but not `gcc-c++` (C++ compiler). The `pyicu` package requires C++ to compile.

On Debian/Ubuntu this is not a problem because `gcc` and `g++` are usually installed together via `build-essential`. On Fedora/RHEL, they are separate packages.

---

### Steps to reproduce

1. Use a fresh Fedora or RHEL system without `gcc-c++` installed.
2. Follow the [Advanced setup](https://zulip.readthedocs.io/en/latest/development/setup-advanced.html) instructions:
   ```bash
   git clone https://github.com/zulip/zulip.git && cd zulip
   ```
3. Run `./tools/provision`.
4. Provisioning fails during `uv sync` with `No such file or directory: 'g++'`.

---

### Suggested fix

Add "gcc-c++" to dependencies in `scripts/lib/setup_venv.py, alongside the existing "gcc" entry.
