## Description
This PR takes over and supersedes the stalled PR #36834, implementing full `RealmAuditLog` infrastructure for custom profile fields and resolving the remaining architectural blockers.

Fixes: #36715

**How changes were tested:**
1. Built a robust new test suite `zerver/tests/test_audit_log.py` using `event_time__gte` assertions to strictly validate the presence and dictionary structure of the `extra_data` log payload.
2. Validated the backfill migration locally via `./manage.py migrate` and verified the synthetic logs generated correctly in the database shell.
3. Manually tested UI actions (Field CRUD operations + User Profile Value changes) using the local development server to ensure log parity.

### Technical Choices & Bug Fixes Highlighted:
- **`acting_user` enforcement:** Made `acting_user` a strictly mandatory keyword-only argument across all custom profile field mutation actions. To resolve system-level testing conflicts, scripts like `populate_db.py` now explicitly pass the default `iago` admin user, while non-audit-log-related tests pass `None`.
- **Value Mutation Coverage:** Added coverage for `USER_CUSTOM_PROFILE_FIELD_VALUE_CHANGED`, ensuring that a user removing their own custom field value is explicitly logged as changing the value to `""`, directly addressing earlier maintainer feedback.
- **Backfill Migration:** Per @sahil839's feedback, included a separate commit with an `elidable=True` backfill migration that bulk-creates synthetic `REALM_CUSTOM_PROFILE_FIELD_CREATED` events for all legacy custom profile fields to maintain DB invariants.
- **Test Suite Date Filtering:** Fixed a flaw in the original PR's test suite where audit logs were queried globally. The new test suite uses `event_time__gte` to ensure parallel test isolation.

### Manual Verification
I verified the logs by opening the local development UI, performing CRUD operations on the custom profile fields, and using `./manage.py shell` to read the raw database objects. The JSON `extra_data` correctly formatted every UI action:
